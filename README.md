# Disney+ — interface de démonstration

Interface responsive en français inspirée de Disney+, réalisée avec JavaScript et Vite. Navigation par catégorie, recherche, favoris pour la session, fiches de titres et carrousel de présentation. Aucun abonnement, authentification ou streaming réel.

## Développement

Node.js 22.12+ ou 24 recommandé.

```sh
npm ci
npm run dev -- --port 5173
```

## Production

```sh
npm run build
npm run preview -- --port 4173
```

Les photographies d’illustration sont chargées depuis Unsplash et les polices depuis Google Fonts. Les images ne sont pas les affiches officielles des œuvres. Les marques et titres appartiennent à leurs propriétaires respectifs.
